# Xenon 介绍短片 · 制作规格

## 目标

让第一次看到 Xenon 的 Mac 用户记住一件事：在任何桌面应用里按下 `⌥ S`，框选看不懂的文字，中文译文就在手边逐行出现，工作不被打断。

## 输出

- HyperFrames，1920×1080，30fps。
- 总长 32.5 秒，共 975 帧。
- 简体中文文案，无旁白。
- 音乐：当前环境没有可用的音乐源（未登录 HeyGen、未安装本地 BGM 模型），先按静音剪辑交付，动作节奏按 100 BPM 的八拍网格安排，后续可加音乐。

## 视觉

- **底色**：纸白 `#F2F1F6`，取自真实 Xenon 窗口；不放渐变，只用平涂与局部阴影。
- **墨色**：`#141418`；次级文字 `#6F6F7A`；细线 `rgba(20,20,24,0.14)`。
- **强调色**：品牌绿 `#99F253`，只出现在选区边框、一个关键词、图标和结尾的 `⌥ S` 键帽。状态绿 `#2AC458` 只随真实截图出现。
- **工作世界**：真实 IDE 截图 `assets/ide-selected.png`，深色 `#12161F`，满幅铺底；截图本身是唯一背景，不加暗角、不加发光。
- **产品世界**：真实窗口截图 `assets/window-*.png` 与 `assets/settings.png`，圆角 22px（按截图比例），投影 `0 28px 60px rgba(20,20,24,0.16)`，不画界面。
- **字体**：中文 `Noto Sans SC`（本地字体文件，可变字重 400–900）；拉丁与数字 `Inter`；快捷键键帽 `Space Mono` 700。
- **字号**：主张 108px（10% 画面高）；场景标题 62px（5.7%）；正文 32px（3.0%）；标注 30px。字距：标题 -0.02em，正文 0。
- **安全区**：所有文字距边缘至少 96px；关键标题距边缘至少 150px。

## 物件

1. **IDE 选区**：真实深色编辑器里的一行英文，蓝色系统选区，保留截图原样。
2. **快捷键键帽**：`⌥` 与 `S` 两枚浅灰键帽，边缘 1px `#B9B9C2`，投影 `0 6px 0 #C9C9D1`，按下时下沉 4px。
3. **框选矩形**：白色 2px 边、四角 12px L 形手柄，内部不填充；这是 macOS 系统选择器的样子，不是产品 UI。
4. **Xenon 窗口**：真实截图，圆角与投影；窗口高度随内容变化，这是产品的真实行为。
5. **设置页**：真实设置截图，5 个渠道、3 个已启用，保留真实文案与开关状态。
6. **App 图标**：`assets/app-icon.png` 原图，用圆角容器裁掉白边，不重绘、不换色。

## 运动

- 到达：`power4.out`，0.45–0.6s。
- 相机：`power2.inOut`，0.8s。
- 退出：`power2.in`，0.22s（比进入短 45%）。
- 穿过：`power3.in`，0.45s。
- 键帽按下：`power2.in` 0.08s，回弹 `back.out(1.7)` 0.18s。
- 图标落版：`back.out(1.4)`，0.55s。
- 文字落定后完全静止；不在标题上做呼吸、漂浮或持续缩放。
- 每场只有一个主运动；次要元素晚 100–200ms，位移为主运动的 50–70%。
- 过场只用四种：推入选区、白闪换世界、窗口横移、设置页推近。

## 禁止

- 黑色或深蓝虚空里漂浮小界面；发光、粒子、光环、镜头光晕。
- 紫色或蓝色渐变、玻璃卡片。
- 米白纸面配衬线标题、斜体强调、`01 / 02` 编号、等宽小字标签、胶囊按钮。
- 三张卡片并排、KPI 网格、把标题压在暗化截图上。
- 标志缩在角落；每一场都用同一种淡入上滑；标题落定后继续漂移。
- 重绘产品界面、编造按钮、改变真实文案与状态。

## 验收帧

- `0.0s`：IDE 英文段落与选区必须可见，第一帧就是缩略图。
- `3.6s`：框选矩形完整，四角手柄清楚。
- `6.2s`：白闪当帧，选区边缘仍可辨认。
- `8.0s`：Xenon 窗口与「本机识别」同时可读。
- `12.0s`：中文译文已出现至少三行，窗口底部模型名可见。
- `16.0s`：结构截图的标题、列表、链接在同一画面内可读。
- `20.5s`：IDE 全景与右上角小窗同时成立，窗口不遮住正文。
- `25.0s`：设置页模型行与开关清晰，左侧文案不压窗口。
- `28.0s`：「截到哪里，译到哪里。」完整落定，绿色选区在「译」上。
- `31.6s`：图标、字标、副标、键帽全部落定并静止。
