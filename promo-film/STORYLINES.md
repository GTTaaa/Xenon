# Xenon 宣传短片 · 三个故事线

## 共同假设

- 成片约 32 秒，1920×1080，30fps，简体中文文案。
- 无旁白，以音乐铺底，动作点配少量真实音效。
- 产品画面全部使用仓库中的真实截图：`screenshots/zh` 与 `app-icon.png`，不重绘界面。
- 结尾行动号召为 `⌥ S`，与产品实际快捷键一致。

## A · 不离开这一页（推荐）

**装置**：一个人的阅读时刻。**形式**：一镜到底的推近与世界转换。

观众先看见一段读不懂的英文技术文档，按下 `⌥ S` 框选后，文字像被提起的纸片，镜头随之推进；纸片翻成中文，落回同一块屏幕的右上角，阅读没有中断。

**前两秒**：深色 IDE 中，英文段落被选中，左侧浮起 `⌥ S` 键帽。

**节拍**：选中英文 → 按下快捷键 → 框选 → 镜头推入、闪白 → Xenon 小窗滑入 → 译文逐行流出 → 结构对照 → 拉回工作区 → 本机识别 → 自选模型 → 图标落版。

**视觉**：深色 IDE 是"工作世界"，纸白与荧光绿是"Xenon 世界"；两个世界共用同一块屏幕，靠框选矩形完成转场。

**声音**：低频脉冲铺底，快捷键与框选各一下轻响，识别时收住，译文流出时细碎字首音，落版一次短促上扬。

**为什么推荐**：它把"任意桌面应用里截图翻译"这件事演给观众看，真实界面、真实结果、真实快捷键，陌生人一遍就能记住。

## B · 一张纸的旅行

**装置**：被截图的那块文字变成一张实体纸。**形式**：对象接力的匹配剪辑。

纸片从 IDE 屏幕里被揭下，穿过一条由代码行与字母组成的暗色通道；在通道尽头被一束光"显影"，翻面后成为排好版的中文，最后贴回屏幕右上角，变成 Xenon 的窗口。

**前两秒**：框选完成的一瞬间，矩形里的文字离开屏幕，边缘带起一层纸纤维。

**节拍**：揭下文字 → 纸片飞行 → 通道中的字母墙 → 显影翻转 → 中文排版形成 → 贴回屏幕 → 窗口展开 → 本机识别与模型选择 → 图标落版。

**视觉**：深色工作台、暖白纸张、荧光绿印色；纸的纤维、折痕和投影承担全部质感。

**声音**：纸张摩擦与机械快门为主，通道段加入低频空气声，显影时一记闷响，之后回到轻快的纸面触碰声。

**风险**：视觉记忆点强，但产品演示只占后半段，第一次看的人可能先记住纸，后记住 Xenon。

## C · 读不懂的那一页

**装置**：语言壁垒本身。**形式**：大字排版、分屏咬合、按拍切换。

满屏英文大字像一堵墙；`⌥ S` 从画面中间切开这堵墙，中文从切口落下。左右分屏逐行对应，标题仍是标题、列表仍是列表、链接仍在原位，最后收进右上角的真实小窗。

**前两秒**：英文大字占满画面，镜头沿着字母横向扫过，字母越来越密。

**节拍**：英文墙 → 快捷键切开 → 中文落下 → 逐行咬合 → 结构对照 → 切进真实小窗 → 本机识别 → 自选模型 → 图标落版。

**视觉**：高对比的黑白版式，荧光绿只出现在切口与关键词；字重与行距承担节奏，不使用卡片。

**声音**：鼓点驱动，每半拍换一次版式；切开时一记锐利 whoosh，中文落下用轻击，后半段音乐减薄，让产品界面自己说话。

**风险**：节奏最有冲击力，适合社交平台；但真实产品出现得晚，更偏品牌片而不是功能介绍。
