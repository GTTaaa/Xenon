# Xenon 宣传短片

约 33 秒、1920×1080 的产品介绍短片，画面风格沿用 App Store 截图的纸白 + 绿色强调色体系。

## 分镜

| 时间       | 场景     | 内容                                                                                |
| ---------- | -------- | ----------------------------------------------------------------------------------- |
| 0–4s       | 品牌开场 | 图标弹入，"Xenon · 截图翻译，语境不丢"                                              |
| 4–8.4s     | 痛点     | PDF / IDE / 终端 / 设计稿 / 视频，浏览器插件够不着，复制粘贴打断阅读                |
| 8.4–17.6s  | 核心演示 | 按下 ⌥ S → 框选 IDE 文字 → 截图闪白 → 窗口滑入 → 本地识别 → 译文流式输出 → 自动复制 |
| 17.6–21.8s | 端侧识别 | 截图 → Vision → 文本 全程在本机，云端 OCR 被划掉                                    |
| 21.8–26s   | 结构保留 | 原文与译文逐行对应，标题、列表、链接、日期原样保留                                  |
| 26–30.2s   | 自带密钥 | DeepSeek / Qwen / ClinePass / OpenAI 兼容，开关与测速指标                           |
| 30–33s     | 结尾     | 图标、Slogan、⌥ + S 快捷键、开源信息                                                |

## 使用

```bash
# 浏览器直接打开 index.html 即可实时循环预览

# 导出某一时刻的单帧，检查画面
node promo/render.mjs --preview 12.5

# 渲染完整视频（默认 30fps，可指定 60fps）
node promo/render.mjs --fps 60
```

产物输出在 `promo/out/`（已被 `.gitignore` 忽略）。渲染依赖本机 Google Chrome 与 ffmpeg，可通过 `CHROME_PATH` 环境变量指定 Chrome 路径。

## 修改文案或节奏

所有动画都由 `index.html` 中的 `window.render(t)` 纯函数驱动，每个场景一个代码块，时间点直接写在其中；调整总时长时同步修改 `window.DURATION`。
